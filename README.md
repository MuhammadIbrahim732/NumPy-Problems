# NumPy Practice & Tutorial Collection

A comprehensive repository containing Python Jupyter/Colab notebooks focused on mastering **NumPy** fundamentals, array manipulations, statistical analysis, and matrix operations.

## 🚀 Contents & Topics

* **Array Creation & Attributes:** Creating arrays using `np.array`, `np.arange`, `np.linspace`, `np.zeros`, `np.ones`, and random functions (`rand`, `randn`, `randint`). Exploring dimensions, size, shape, and data types.
* **Indexing & Slicing:** Extracting elements, vectors, and sub-matrices using standard and boolean indexing.
* **Array Operations & Broadcasting:** Performing arithmetic operations, vector-scalar broadcasting, and handling deep vs. shallow copies (`copy()` vs. `view()`).
* **Matrix Operations:** Reshaping, resizing, matrix multiplication (`@`, `np.dot`), element-wise multiplication, and transposing (`T`).
* **Applied Problem Sets:** Step-by-step practical data exercises including:
  * Student Marks Analysis
  * Random Sales Data Tracking
  * Exam Statistics (Mean, Median, Mode, Variance, Standard Deviation)
  * Employee Salary Matrix Operations
  * Weather Temperature Analysis across Multiple Weeks
